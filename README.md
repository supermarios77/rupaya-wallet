# Rupaya Wallet

Customised Ethereum mobile wallet for Rupaya, built on AlphaWallet

> **Not maintained.** This project is no longer actively developed and reflects an early stage of my development.

## Overview

A fork of AlphaWallet, the open-source Ethereum mobile wallet for Android, customised for Rupaya. Changes include a custom app icon, Rupaya branding, and Rupaya as the default token.

## What changed from AlphaWallet

- **App icon:** replaced with Rupaya branding.
- **Accent color:** updated to match Rupaya's visual identity.
- **Default token:** Rupaya set as the default cryptocurrency.

## Tech stack

- **Language:** Java
- **Platform:** Android
- **Upstream:** AlphaWallet
